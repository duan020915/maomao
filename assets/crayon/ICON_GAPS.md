# 待补的手绘图案

当前 PNG 素材已覆盖四个主导航、登录、通知、发布、点赞、评论、添加照片，以及页面装饰。以下控件在素材包里没有含义对应且裁切合格的图案，暂时使用文字或符号：

- 关闭、返回、上一页、下一页、展开和收起：弹窗、日历与圈子切换使用的方向符号。
- 约一约投票：可以参加、不能参加的勾与叉。现在只显示明确的文字。
- 时间轴：时钟图案。标题暂时只显示日期与文字。
- 审批：通过、驳回、收据图案。现在使用文字。
- 野餐篮：示例邀约正文原有的篮子 emoji 已移除，若需要该装饰可单独绘制。
- 刷新：顶栏按钮已移除，目前无需绘制。

头像和用户自己输入的 emoji 属于内容，不作为界面指示图标批量替换。新增图案请保持透明背景、完整笔触与原始比例。
