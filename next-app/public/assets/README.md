# 冒冒网站素材

- `moods/`：仓库原有的 12 张透明 PNG 心情贴纸。本页直接复用。
- `crayon/`：从用户提供的 v3 ZIP 中挑选的原始蜡笔 PNG。使用位置和质量检查见 `crayon/ASSET_AUDIT.md`。
- `icons/`：从仓库原有 `assets/icons/` 复制的 SVG 图标；授权和来源见本目录的 `LICENSE`、`CREDITS.md`。
- `papers/`、`tapes/`、`stickers/`：为后续审核过的独立素材预留。当前纸条、胶带效果由页面样式实现，没有新增图片素材。

现有心情贴纸均带 alpha 透明通道，但部分图案接触图片边缘。若以后需要放大印刷或重新裁切，应逐张核对源文件。
