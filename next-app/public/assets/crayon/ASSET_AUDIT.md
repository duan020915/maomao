# v3 素材与手机版「冒个泡」对应

来源：用户提供的 `maomao-crayon-assets-v3.zip`。这里仅复制原始透明 PNG；没有重画、改色、拉伸或包装成 SVG。

| 界面用途 | 当前素材 |
| --- | --- |
| 底部导航 | `icons/nav-home.png`、`nav-calendar.png`、`nav-meet.png`、`nav-approval.png`、`nav-friends.png`、`nav-profile.png` |
| 通知 | `icons/notification.png` |
| 点赞 | `icons/like-outline.png`、`like-filled.png` |
| 动态装饰 | `papers/paper-blue.png`、`paper-pink.png`、`paper-yellow.png`；`tapes/tape-yellow.png`、`tape-pink.png`、`tape-blue.png` |
| 心情贴纸 | `stickers/sticker-sun.png`、`sticker-star.png`、`sticker-heart.png`、`sticker-sleepy.png`、`mood-cloud.png`、`mood-sprout.png`；缺少对应 v3 素材的心情继续使用仓库原有 PNG |
| 标题点缀 | `stickers/doodle-star.png` |

检查中发现：

- `paper-green.png` 右侧混入黄色图案，暂不使用。
- `camera.png` 下方有零散深色像素，暂不使用。
- v3 纸张只有约 119–189 像素宽。它们按原始比例作为局部装饰显示，没有放大到整张手机动态的宽度，以免笔触模糊。
- v3 只有部分心情图案；其余心情沿用项目现有的 12 张透明 PNG。上传头像素材不在这次范围内，当前仍用文字占位头像。
